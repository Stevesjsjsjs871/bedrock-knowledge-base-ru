# Глоссарий Minecraft Bedrock Add-Ons

| Термин | Объяснение |
|---|---|
| Add-On | Набор пакетов, расширяющий или меняющий содержимое Minecraft Bedrock. |
| Behavior Pack (BP) | Пакет игровых данных и логики: поведение сущностей и другие правила. |
| Resource Pack (RP) | Пакет визуальных и звуковых ресурсов: текстуры, модели, анимации и звуки. |
| Entity | Сущность игрового мира: моб, животное, снаряд или другой объект. |
| Entity JSON | JSON-определение сущности с идентификатором и описанием поведения. |
| Component | Именованный блок данных, задающий характеристику или поведение сущности. |
| Component group | Группа компонентов, которую можно включать или отключать для изменения состояния. |
| Event | Именованная реакция, запускающая поддерживаемые действия или переключение групп. |
| Identifier | Строковый идентификатор, часто в формате `namespace:name`. |
| Namespace | Пространство имён, помогающее избегать конфликтов идентификаторов. |
| `format_version` | Версия формата данных, не обязательно версия игры. |
| Stable | Стабильная ветка API или документации согласно источнику. |
| Preview | Предварительная возможность, которая может измениться или исчезнуть. |
| Molang | Язык выражений, используемый в разных системах Minecraft Bedrock. |
| Geometry | Описание формы и структуры модели сущности. |
| Animation Controller | Логика выбора состояний и переходов анимации. |
| Spawn Rules | Правила, определяющие условия появления сущностей. |
| Content Log | Журнал диагностики, помогающий обнаружить ошибки содержимого. |
| UUID | Уникальный идентификатор в манифестах и зависимостях. |
| Scripting API | JavaScript API для поддерживаемой игровой логики. |
| JSON UI | Система интерфейса на основе JSON в поддерживаемых версиях. |
| Loot table | Таблица правил выпадения предметов. |
| Manifest | Файл метаданных пакета: UUID, модули, версии и зависимости. |
| Behavior goal | Компонент или правило, описывающее цель поведения сущности. |
| Filter | Условие, проверяющее свойства сущности, окружение или контекст события. |
| Sensor | Механизм наблюдения за условиями вокруг сущности и запуска реакции. |

Точные поля и поведение сверяйте с документацией нужной версии.
