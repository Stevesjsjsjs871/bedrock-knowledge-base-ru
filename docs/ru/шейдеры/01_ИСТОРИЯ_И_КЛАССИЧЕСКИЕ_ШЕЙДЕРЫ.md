# История шейдеров Bedrock: классическая эпоха

## Почему старые шейдеры важны

До перехода Bedrock на RenderDragon сторонние авторы создавали визуальные паки, рассчитанные на старый графический путь мобильных устройств и конкретные версии игры. Они могли менять освещение, туман, воду, небо и цветовую картинку через техники, которые не являются универсальным API для всех последующих версий.

## Главный рубеж: Bedrock 1.16.200

Обновление 1.16.200 принесло RenderDragon на поддерживаемые платформы и сломало совместимость многих старых сторонних шейдеров. В официальном Minecraft Feedback есть давняя тема, где пользователи сообщали о поломке shader packs после этого перехода: [Shader support for Render Dragon](https://feedback.minecraft.net/hc/en-us/community/posts/360075868792-Shader-support-for-Render-Dragon). Это community-feedback, а не нормативная спецификация API, поэтому используем его как историческое свидетельство.

## Как каталогизировать старый шейдер

Для каждого найденного проекта фиксируйте:

- исходное название и автора;
- точную версию игры, на которой автор его демонстрировал;
- устройство и ОС (например, Android, iOS, Windows);
- графический API / рендерер, если он известен;
- исходный формат и структуру архива;
- требуемые экспериментальные настройки;
- известные ограничения и последнюю дату обновления;
- исходную страницу, видео и таймкод;
- разрешение автора и лицензию на распространение.

Не считайте видео с красивой картинкой доказательством совместимости с актуальной игрой. Видео может показывать старую версию, модифицированный клиент, монтаж или устройство с другой графической возможностью.

## Частые ошибки при поиске старых шейдеров

1. **«Подходит для MCPE»** — слишком расплывчато: MCPE использовалось для множества версий, а совместимость менялась.
2. **«Работает на Android»** — не указывает версию ОС, GPU, игру и рендерер.
3. **«Исправленная версия»** — нужно проверить, что именно исправлено и для какого выпуска.
4. **Переименование файлов** — само по себе не портирует шейдер на другой рендерер.
5. **Пак выглядит как шейдер, значит он шейдер** — некоторые паки меняют лишь текстуры, fog/sky assets или настройки доступной графики.

## Известные названия: только исторические ориентиры

В обсуждениях старых Bedrock/MCPE встречаются ESBE, ESBE 2G/5G, Newb Shader и другие названия. Наличие имени в историческом списке не подтверждает безопасность файла, законность зеркала или поддержку текущей версии. Перед публикацией конкретной записи нужны первичная страница проекта, версия игры и воспроизводимый тест.

Пример community-обсуждения старых шейдеров: [Reddit — pre-RenderDragon shaders](https://www.reddit.com/r/MCPE/comments/1wih54v/i_miss_the_days_of_pre-renderdragon_shadersusing/). Это свидетельство сообщества, не официальный источник и не гарантия работы.

## Как честно писать о совместимости

Используйте формулировки:

- «Автор заявляет поддержку версии X» — если есть только страница релиза.
- «Импортируется в версии X» — если проверен только импорт.
- «Отображается в версии X на устройстве Y» — если проверен визуальный результат.
- «Проверено повторно на версии X» — если сохранены условия и шаги воспроизведения.

Не писать «работает на всех версиях» без матрицы испытаний.
