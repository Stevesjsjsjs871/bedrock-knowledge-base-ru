# События и триггеры сущностей

События Entity JSON связывают поддерживаемое действие с изменением состояния сущности. Точная семантика зависит от типа события и версии игры.

## Как разбирать событие
1. Причина: что вызывает событие — команда, таймер, компонент или другое условие.
2. Реакция: какие действия разрешены внутри события.
3. Состояние: какие component groups добавляются или удаляются.
4. Проверка: можно ли воспроизвести переход в игре и увидеть ошибку в Content Log.

## Схематичный пример
```json
{
  "component_groups": {
    "example:alert": {
      "minecraft:movement": { "value": 0.35 }
    }
  },
  "events": {
    "example:become_alert": {
      "add": { "component_groups": ["example:alert"] }
    }
  }
}
```
Это иллюстрация идеи переключения группы; проверьте точную структуру для используемой версии.

## Диагностика
- Проверьте совпадение имён событий во всех ссылках.
- Убедитесь, что упомянутые component groups существуют.
- Не предполагайте, что объявленное событие запускается автоматически.
- Сверяйте разрешённые действия с официальной документацией.
