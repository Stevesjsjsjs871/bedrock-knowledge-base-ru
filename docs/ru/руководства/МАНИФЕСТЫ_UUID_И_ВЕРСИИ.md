# Манифесты, UUID и версии

> Статус: `needs-review` для конкретных полей схемы. Перед выпуском проверяйте актуальный формат манифеста.

## Что делает manifest.json
Манифест описывает пакет, его модули, UUID и версии. По этим данным Minecraft распознаёт пакет и может сопоставлять зависимости.

## Основные правила
- Используйте уникальный UUID для каждого требующего его заголовка и модуля.
- Не копируйте UUID из учебного примера в несколько пакетов.
- Поддерживайте версии в правильном типе и формате, который ожидает выбранная схема.
- Проверяйте, что зависимость ссылается на правильный UUID и версию.
- Не путайте `format_version` файла манифеста с версией игры или версией вашего Add-On.

## Типичные ошибки
1. Одинаковые UUID у разных модулей.
2. Зависимость указывает на другой пакет.
3. Поле записано в формате, который не поддерживается используемой версией.
4. Манифест валиден как JSON, но не соответствует схеме Minecraft.
5. Изменён UUID, но зависимость в другом пакете осталась старой.

## Порядок диагностики
1. Проверьте JSON-синтаксис.
2. Сверьте структуру с актуальным примером Microsoft.
3. Проверьте UUID, версии и зависимости.
4. Перезапустите тест с включёнными пакетами.
5. Прочитайте Content Log.
