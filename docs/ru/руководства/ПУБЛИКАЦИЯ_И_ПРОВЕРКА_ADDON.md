# Проверка Add-On перед передачей или публикацией

Этот список помогает проверить целостность проекта. Он не заменяет требования Marketplace, платформы или конкретной версии игры.

## Структура проекта

- [ ] BP и RP разделены по назначению.
- [ ] В каждом пакете есть корректный манифест.
- [ ] UUID уникальны там, где этого требует схема.
- [ ] Версии модулей и зависимости согласованы.
- [ ] Файлы лежат в правильных каталогах и имеют ожидаемые расширения.
- [ ] Нет временных файлов редактора, локальных копий исходников или секретов.

## Ссылки и ресурсы

- [ ] Идентификаторы сущностей, блоков и предметов согласованы.
- [ ] Все текстуры, геометрия, анимации и контроллеры существуют.
- [ ] Все ключи локализации имеют соответствующие значения.
- [ ] Ссылки между BP и RP проверены.
- [ ] Удалены ненужные ресурсы и определения, если они не используются.

## Поведение

- [ ] Основной сценарий проверен в чистом тестовом мире.
- [ ] Проверены крайние случаи и неправильные условия.
- [ ] Проверены события появления и вызов через команды, если это важно.
- [ ] Проверены взаимодействия, дропы и рецепты.
- [ ] Проверены конфликты с другими активными пакетами.
- [ ] Изучен Content Log, ошибки объяснены или устранены.

## Совместимость

- [ ] Записана версия игры, в которой тестировали Add-On.
- [ ] Stable и Preview не смешаны без явной маркировки.
- [ ] Зависимости Script API соответствуют целевой версии.
- [ ] Указаны известные ограничения и неподдерживаемые сценарии.

## Лицензии и документация

- [ ] Проверены лицензии исходных текстур, моделей, звуков и кода.
- [ ] Сохранены требуемые уведомления и атрибуция.
- [ ] Документация объясняет установку, возможности и ограничения.
- [ ] Примеры JSON соответствуют опубликованной версии проекта.
