# Версии Script API и зависимости манифеста

> Статус: обзор принципов. Текущую версию каждого модуля и соответствие версии игры проверяйте в официальной таблице Microsoft Learn.

## Две разные версии

Версия Minecraft и версия Script API — не одно и то же. В манифесте Behavior Pack зависимость на модуль, например @minecraft/server, указывает версию API. Эта версия имеет собственную нумерацию.

Поэтому нельзя выбирать версию API простым копированием номера версии игры. Сначала определите целевую версию игры, затем сверяйте совместимую версию модуля.

## Stable, Beta и Internal

- **Stable** — публичный стабильный трек API. По возможности предпочитайте его для пакетов, которым нужна предсказуемая совместимость.
- **Beta** — экспериментальный трек. API может меняться несовместимым образом; использование обычно требует включения соответствующих экспериментов в мире.
- **Internal** — внутренние интерфейсы, не предназначенные для обычных пользовательских Add-On.

Суффиксы версии важны. Не удаляйте -beta и не считайте beta-версию эквивалентом стабильной версии с тем же номером.

## Практический порядок выбора

1. Определите минимальную версию Minecraft, которую должен поддерживать проект.
2. Найдите таблицу соответствия версии игры и версии нужного Script API.
3. Проверьте, доступен ли требуемый класс, метод и событие в выбранном треке.
4. Укажите точную зависимость в manifest.json.
5. Проверьте пакет на минимальной поддерживаемой версии игры.
6. Если API экспериментальный, явно укажите это в README проекта и инструкции по тестированию.

## Почему «у меня компилируется» недостаточно

Типы, доступные в установленном npm-пакете, не гарантируют, что конкретная игровая сборка предоставляет тот же интерфейс. Сверяйте типовые определения, документацию и фактическую версию Minecraft.

## Диагностика проблем

- Ошибка импорта: проверьте имя модуля и зависимость манифеста.
- Неизвестный метод: проверьте трек и версию API.
- Пакет требует эксперимент: проверьте, действительно ли функция относится к Beta API.
- Работает в Preview, но не в Stable: проверьте, не использована ли preview-only возможность.
- Ошибка после обновления игры: проверьте журнал изменений Script API.
