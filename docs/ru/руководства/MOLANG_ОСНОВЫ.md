# Molang: основы выражений

> Статус: учебное объяснение; сверяйте конкретные функции и ограничения с официальной справкой для целевой версии игры.

## Что такое Molang

Molang — встроенный в Minecraft Bedrock язык выражений. Он позволяет вычислять значения на основе математических выражений, состояния сущности и специальных запросов `query.*`. Его используют в JSON-пакетах, в том числе для анимаций, условий и некоторых динамических параметров. Это не замена JavaScript API: Molang предназначен для компактных выражений внутри систем контента.

Официальные материалы:
- [Введение в Molang](https://learn.microsoft.com/en-us/minecraft/creator/documents/molang/introduction?view=minecraft-bedrock-stable)
- [Синтаксис Molang](https://learn.microsoft.com/en-us/minecraft/creator/documents/molang/syntax-guide?view=minecraft-bedrock-stable)

## Простейшее выражение

```molang
math.sin(query.anim_time * 1.23)
```

Здесь вызывается математическая функция, а `query.anim_time` предоставляет значение игрового контекста. Доступность конкретного запроса зависит от места, где вычисляется выражение.

## Переменные

В выражениях часто встречаются три пространства имён:

- `query.*` — данные, предоставляемые контекстом Minecraft;
- `variable.*` — переменные, предназначенные для хранения состояния в поддерживающем их контексте;
- `temp.*` — временные значения для вычислений внутри выражения.

Не считайте их взаимозаменяемыми: у них разные назначения и жизненный цикл. Проверяйте документацию конкретного контекста, прежде чем полагаться на сохранение значения между кадрами или вызовами.

Пример составного выражения:

```molang
temp.a = math.sin(query.anim_time);
temp.b = math.cos(query.life_time);
return temp.a + temp.b;
```

В многооператорном выражении используйте завершающие точки с запятой. Если нужно вернуть вычисленный итог, явно укажите `return`.

## Условия

Условные выражения позволяют выбирать значение в зависимости от условия. В разных контекстах Minecraft ожидает разные формы выражений, поэтому переносить фрагмент Molang из одного JSON-файла в другой без проверки нельзя.

Условный шаблон для изучения:

```molang
query.is_on_ground ? 1.0 : 0.0
```

Перед использованием проверьте, поддерживается ли `query.is_on_ground` в нужном контексте и версии.

## Ошибки и диагностика

- Деление на ноль и некорректные значения могут приводить к результату `0.0` и сообщениям об ошибках содержимого.
- Опечатка в имени query или переменной может не приводить к очевидной ошибке компиляции — проверяйте Content Log.
- Строки чувствительны к регистру иначе, чем большинство идентификаторов Molang; сохраняйте регистр строковых значений.
- Некоторые правила поведения Molang зависят от `min_engine_version` пакета.
- Не переносите выражения из Preview в Stable без проверки.

## Практический порядок работы

1. Найдите нужный контекст в документации.
2. Проверьте существование query, переменной или математической функции.
3. Начните с короткого выражения, возвращающего простое значение.
4. Проверьте результат в игре и изучите Content Log.
5. Только затем добавляйте условия и составные вычисления.
