# JSON UI: обзор

> Статус: вводный обзор. JSON UI зависит от внутренней схемы интерфейса Minecraft и может быть чувствителен к версии игры. Проверяйте конкретные свойства и селекторы по актуальным community-материалам и тестируйте в целевой версии.

## Что такое JSON UI

JSON UI — система описания части пользовательского интерфейса Minecraft Bedrock с помощью JSON-файлов. Она отличается от обычного Resource Pack: текстуры и изображения задают визуальные ресурсы, а JSON UI описывает структуру экранов, элементы, привязки и оформление поддерживаемых интерфейсов.

Это не универсальный способ изменить любой экран игры: доступность и устойчивость конкретных элементов зависят от реализации Minecraft и версии.

## Что нужно понять перед изменением интерфейса

- **Иерархия элементов.** Интерфейс состоит из вложенных элементов и контейнеров.
- **Идентификаторы.** Элементы могут ссылаться на другие определения по имени.
- **Bindings и данные.** Некоторые элементы отображают данные игрового интерфейса через предусмотренные системой привязки.
- **Ресурсы.** Изображения, текстуры и шрифты должны существовать и быть подключены корректно.
- **Переопределения.** Изменения могут конфликтовать с другим Resource Pack или с изменениями самой игры.

## Безопасный рабочий процесс

1. Создайте отдельный тестовый Resource Pack.
2. Сохраните копию исходного файла, который собираетесь менять.
3. Меняйте одну небольшую область за раз.
4. Не удаляйте неизвестные ключи без понимания их назначения.
5. Проверяйте интерфейс в нужном разрешении и на нужном устройстве.
6. Проверяйте поведение после изменения порядка пакетов.
7. Фиксируйте версию игры, в которой проверен результат.

## Почему JSON UI требует особой осторожности

В отличие от стабильного публичного API, некоторые внутренние элементы UI могут изменяться между обновлениями. Пример из старой версии может загружаться с ошибками или давать неожиданный результат в новой версии. Не помечайте неподтверждённый пример как Stable только потому, что JSON синтаксически корректен.

## Диагностика

- Проверяйте корректность JSON и все идентификаторы.
- Убедитесь, что файл находится в ожидаемом каталоге пакета.
- Проверьте, какой пакет имеет приоритет при конфликте ресурсов.
- Ищите сообщения об ошибках UI в логах игры.
- Уберите последние изменения, если экран перестал отображаться, и возвращайте их по одному.
