# Компоненты сущностей

Компонент — именованный объект данных, который задаёт характеристику или поведение сущности. Например, компонент здоровья задаёт параметры здоровья, а компонент поведения описывает одну из целей AI. Идентификаторы компонентов не переводятся.

## Компоненты и группы
- Компоненты в базовом разделе действуют в исходном состоянии.
- Component groups описывают наборы компонентов для отдельных состояний.
- События могут добавлять и удалять группы, меняя набор компонентов сущности.

## Как читать страницу компонента
Запишите назначение, имя, поля и типы, значения по умолчанию, ограничения версии, минимальный JSON-пример, типичные ошибки и первоисточник.

Пример формы данных:
```json
{
  "minecraft:health": { "value": 20, "max": 20 }
}
```
Проверяйте доступность и ограничения компонента для нужной версии.

Официальные источники: [Entity Reference Stable](https://learn.microsoft.com/en-us/minecraft/creator/reference/content/entityreference/?view=minecraft-bedrock-stable) и [Component List](https://github.com/MicrosoftDocs/minecraft-creator/blob/main/creator/Reference/Content/EntityReference/Examples/ComponentList.md).

Не объединяйте похожие компоненты только по названию: сравните поля, формат, условия использования и версии.
