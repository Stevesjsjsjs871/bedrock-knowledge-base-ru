# Поиск по исходным страницам

Каталог статей помогает найти документ по заголовку. Когда нужен конкретный компонент, JSON-ключ, идентификатор или фрагмент API, используйте полнотекстовый поиск по локальным копиям первоисточников.

## Подготовка

Из корня репозитория выполните один раз (или повторите для обновления копий):

```bash
python tools/sync_sources.py
```

Затем ищите по содержимому:

```bash
python tools/search_sources.py minecraft:health
python tools/search_sources.py "minecraft:behavior.nearest_attackable_target"
python tools/search_sources.py "spawn_rate" --limit 15
python tools/search_sources.py "@minecraft/server" --source minecraft-creator
python tools/search_sources.py "query.is_on_ground" --source bedrock-wiki
```

Команда показывает заголовок страницы, относительный путь, примерную строку совпадения, короткий фрагмент и ссылку на исходник в GitHub. Она читает файлы из `sources/` и не отправляет их в сторонний поисковый сервис.

## Как искать точнее

- Начинайте с точного имени, например `minecraft:health`, `format_version`, `world.afterEvents`.
- Если результатов много, добавьте тип ресурса или сузьте источник через `--source`.
- Если ничего не найдено, уберите часть слов: поиск требует, чтобы каждый отдельный токен присутствовал в файле, но не обязательно в одной строке.
- Сначала откройте найденный первоисточник и проверьте ветку/версию. Само совпадение не доказывает совместимость с вашей версией игры.
- Каталог не включает все бинарные файлы и не гарантирует, что каждый результат актуален для Stable.

## Ограничения

Поиск ранжирует совпадения по заголовку, пути, заголовкам разделов и наличию терминов в тексте. Это лёгкий локальный поиск, а не семантическая модель: синонимы и скрытый смысл он не определяет. Номер строки указывает на наиболее релевантную строку, найденную в локальной копии; сверяйте содержимое с первоисточником.
