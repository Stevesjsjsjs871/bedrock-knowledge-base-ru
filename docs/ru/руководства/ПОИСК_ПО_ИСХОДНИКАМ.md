# Поиск по исходным страницам

Каталог статей помогает найти документ по заголовку. Для конкретного компонента, JSON-ключа, идентификатора или API используйте полнотекстовый поиск по локальным копиям первоисточников.

## Подготовка

Из корня репозитория выполните команду синхронизации один раз или повторите её для обновления копий:

    python tools/sync_sources.py

Синхронизация включает Bedrock Wiki, Microsoft Creator Docs и официальный репозиторий Mojang Bedrock Schemas. Схемы добавляют машинно-читаемые определения JSON BP/RP и отличаются от документационных страниц.

## Примеры поиска

    python tools/search_sources.py minecraft:health
    python tools/search_sources.py "minecraft:behavior.nearest_attackable_target"
    python tools/search_sources.py spawn_rate --limit 15
    python tools/search_sources.py @minecraft/server --source minecraft-creator
    python tools/search_sources.py query.is_on_ground --source bedrock-wiki
    python tools/search_sources.py componentCount --source bedrock-schemas
    python tools/search_sources.py format_version --source bedrock-schemas

Команда показывает заголовок файла, относительный путь, строку совпадения, фрагмент и ссылку на upstream. Поиск выполняется по локальным файлам и не отправляет запрос стороннему поисковому сервису.

## Как выбирать источник

- **Поведение/API и поддержка версии:** сначала Microsoft Creator Docs и точная ветка Stable/Preview.
- **Структура JSON и допустимые поля:** Creator Docs + [Mojang Bedrock Schemas](https://github.com/Mojang/bedrock-schemas), затем минимальный тест в игре.
- **Реальный образец файла:** [Mojang Bedrock Samples](https://github.com/Mojang/bedrock-samples) или [Microsoft Minecraft Samples](https://github.com/microsoft/minecraft-samples); указывайте ветку/тег.
- **Подробный community-процесс:** Bedrock Wiki и инструменты вроде Blockbench/bridge.; перепроверьте поля и результат в официальных источниках.
- **Готовый Add-On/текстур-пак:** [реестр источников](../справочник/РЕЕСТР_ИСТОЧНИКОВ_BEDROCK.md). Каталоги паков показывают пользовательские публикации, а не гарантированную корректность.

## Как искать точнее

- Начинайте с точного имени: minecraft:health, format_version, world.afterEvents.
- Если результатов много, добавьте термин или сузьте источник через --source.
- Поиск возвращает файлы с совпадением хотя бы одного токена и выше ранжирует файлы, содержащие все токены; совпадения могут находиться в разных строках.
- Если ничего не найдено, проверьте успешность синхронизации, попробуйте часть идентификатора или название типа файла.
- Откройте найденный первоисточник и проверьте ветку/версию. Само совпадение не доказывает совместимость с вашей версией игры.

## Ограничения

Поиск ранжирует текстовые совпадения, а не смысл. Он не индексирует изображения и другие бинарные ассеты и не подтверждает совместимость с конкретной версией Bedrock. Номер строки относится к локальной копии; сверяйте актуальность с первоисточником.
