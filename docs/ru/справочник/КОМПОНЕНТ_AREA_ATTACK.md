# Компонент minecraft:area_attack — урон по области

Компонент наносит урон сущностям, которые входят в заданный радиус. Он подходит для контакта с опасной сущностью, например для слизня, но сам по себе не заменяет AI-поведение, выбор цели или обычную атаку ближнего боя.

**Официальный источник:** [Microsoft Learn — minecraft:area_attack (Stable)](https://learn.microsoft.com/en-us/minecraft/creator/reference/content/entityreference/examples/entitycomponents/minecraftcomponent_area_attack?view=minecraft-bedrock-stable)

## Поля

| Поле | Тип / значение по умолчанию | Назначение |
|---|---|---|
| `cause` | строка из списка причин урона; не задано по умолчанию | Тип урона. В примере Magma Cube используется `entity_attack`. |
| `damage_cooldown` | десятичное число, по умолчанию `0` | Интервал в секундах между нанесением урона цели. |
| `damage_per_tick` | целое число, по умолчанию `2` | Количество урона за тик при применении эффекта. |
| `damage_range` | десятичное число, по умолчанию `0.2` | Близость, на которой урон применяется. |
| `death_message_override` | строка; не задано | Ключ локализации сообщения о смерти от этого урона; пустое значение использует стандартное сообщение для причины урона. |
| `entity_filter` | фильтр Minecraft; не задан | Ограничивает сущности, которым разрешено наносить урон. |
| `play_attack_sound` | логическое значение, по умолчанию `true` | Проигрывать ли звук атаки. |
| `use_self_as_damage_source` | логическое значение, по умолчанию `true` | Считать ли владельца компонента источником урона. Требует format_version не ниже `1.26.30`. |

Проверяйте типы и допустимые значения по официальной странице для целевой версии: формат компонента может расширяться.

## Минимальная схема для эксперимента

Это иллюстрация структуры, а не готовая сущность целиком. Добавляйте компонент в корректный раздел компонентов Entity JSON и проверьте его на своей версии игры.

~~~json
{
  "minecraft:area_attack": {
    "cause": "entity_attack",
    "damage_cooldown": 0.5,
    "damage_per_tick": 2,
    "damage_range": 0.2,
    "entity_filter": {
      "test": "is_family",
      "subject": "other",
      "value": "player"
    }
  }
}
~~~

## Важное отличие от minecraft:attack

- `minecraft:area_attack` наносит урон сущностям, которые находятся в пределах области, с учётом фильтра и времени перезарядки.
- `minecraft:attack` задаёт урон обычной атаки ближнего боя и возможные эффекты при попадании.
- AI goals определяют, как сущность выбирает цель и пытается атаковать. Наличие урона по области само по себе не гарантирует, что сущность будет искать игрока или преследовать его.

## Особенность источника урона

Свойство `use_self_as_damage_source` добавлено для формата `1.26.30`. Если указать `false`, другие сущности не должны выбирать атакующую сущность как цель для ответной атаки именно на основании этого урона. Для более старых форматов не переносите это поле без проверки совместимости.

## Диагностика

1. Убедитесь, что сущность корректно загружается и Content Log не показывает ошибку компонента.
2. Временно используйте простой фильтр на игрока и тестируйте в отдельном мире.
3. Проверяйте отдельно расстояние, величину урона и `damage_cooldown`; меняйте только один параметр за раз.
4. Если урон проходит по неподходящим целям, проверьте `entity_filter` и его субъект `other`.
5. Если сущность не преследует игрока, ищите проблему в AI goals и фильтрах выбора цели, а не только в `area_attack`.
6. Отдельно тестируйте `use_self_as_damage_source` на версии, поддерживающей format_version `1.26.30` или новее.

**Статус:** объяснение составлено по официальной документации; пример не объявляется проверенным в игре.
