# Компонент minecraft:attack

**Назначение:** задаёт урон ближней атаки сущности и необязательный статус-эффект, который применяется к поражённой цели.

Источник: [Microsoft Learn — minecraft:attack (Stable)](https://learn.microsoft.com/en-us/minecraft/creator/reference/content/entityreference/examples/entitycomponents/minecraftcomponent_attack?view=minecraft-bedrock-stable).

## Поля

| Поле | Тип | Назначение |
|---|---|---|
| damage | число, пара значений или объект диапазона | Урон атаки; может задаваться как фиксированное значение или диапазон |
| effect_name | строка | Идентификатор эффекта состояния, применяемого к цели |
| effect_duration | число | Длительность эффекта в секундах |
| effect_amplifier | целое число | Уровень усиления эффекта |

Официальная таблица указывает отсутствие универсального значения по умолчанию для damage и effect_name. Для необязательных параметров эффекта описаны значения по умолчанию: 0 для effect_duration и effect_amplifier. Сверяйте актуальную страницу Stable перед использованием новых полей.

## Пример: фиксированный урон

~~~json
{
  "minecraft:attack": {
    "damage": 5
  }
}
~~~

В этом примере компонент задаёт пять единиц урона для ближней атаки. Это не означает, что сущность автоматически найдёт цель или начнёт атаковать: для этого требуется подходящее поведение AI, например melee_attack, и логика выбора цели, если она нужна.

## Пример: диапазон урона

~~~json
{
  "minecraft:attack": {
    "damage": {
      "range_min": 3,
      "range_max": 6
    }
  }
}
~~~

Допустимые формы damage описаны официально: число, массив из минимального и максимального значений либо объект с range_min и range_max. Для проекта выбирайте одну форму и придерживайтесь её; не смешивайте примеры из разных версий без проверки.

## Пример с эффектом

~~~json
{
  "minecraft:attack": {
    "damage": 4,
    "effect_name": "slowness",
    "effect_duration": 3,
    "effect_amplifier": 0
  }
}
~~~

Пример иллюстрирует структуру полей, но не объявляется проверенным в игре. Проверьте допустимое имя эффекта и его фактическое применение на целевой версии. В формате 1.26.30 поведение effect_amplifier было исправлено: в более ранних форматах значение могло игнорироваться. Если эффект критичен, обязательно учитывайте версию формата.

## Что компонент не делает

- Не выбирает врагов и не запускает AI.
- Не определяет дальность обнаружения цели.
- Не заменяет поведение атаки, например minecraft:behavior.melee_attack.
- Не гарантирует, что любая сущность способна нанести урон в любой ситуации.

## Диагностика

| Симптом | Что проверить |
|---|---|
| Моб не атакует | Наличие поведения атаки и выбора цели, приоритеты AI, фильтры |
| Атака есть, урон не тот | Значение damage, форму диапазона и другие механики урона |
| Эффект не применяется | Идентификатор эффекта, длительность, формат версии и Content Log |
| Эффект слишком слабый | effect_amplifier и версию формата; не предполагайте одинаковое поведение старых версий |

## Проверочный список

- [ ] JSON корректен и компонент расположен в нужном разделе сущности.
- [ ] Настроено отдельное поведение, которое инициирует ближнюю атаку.
- [ ] Проверены минимальный и максимальный урон.
- [ ] Эффект проверен на целевой версии, если он используется.
- [ ] Зафиксированы версия игры, версия формата и результат теста.
