# Attack Damage — значение урона атаки

В Entity Reference Microsoft Learn запись **Attack Damage** описывает, сколько урона сущность наносит при атаке. В отличие от `minecraft:attack`, который также может задавать эффекты при попадании, эта запись содержит отдельное значение `value`.

**Официальный источник:** [Microsoft Learn — Attack Damage (Stable)](https://learn.microsoft.com/en-us/minecraft/creator/reference/content/entityreference/examples/entitycomponents/minecraftcomponent_attack_damage?view=minecraft-bedrock-stable)

## Поле

| Поле | Тип / значение по умолчанию | Назначение |
|---|---|---|
| `value` | диапазон целых чисел; не задан | Определяет, сколько урона наносится цели при атаке. |

Официальная страница указывает диапазон целых чисел и не задаёт значение по умолчанию. Поэтому не рассчитывайте на подразумеваемое число: указывайте значение явно и сверяйте поддержку поля с целевой версией.

## Схематичный пример

~~~json
{
  "minecraft:attack_damage": {
    "value": 5
  }
}
~~~

Используйте этот фрагмент как иллюстрацию поля, а не как полный JSON сущности. Если в актуальном описании вашей версии используется иное расположение или форма компонента, следуйте схеме именно этой версии.

## Не путайте с minecraft:attack

- `Attack Damage` описывает значение урона, наносимого при атаке.
- `minecraft:attack` задаёт урон ближней атаки, может использовать диапазон и дополнительные статус-эффекты при попадании.
- `minecraft:area_attack` наносит урон находящимся рядом сущностям по отдельным правилам.
- `minecraft:damage_sensor` настраивает реакцию сущности на входящий урон, а не силу её собственной атаки.

## Проверка

1. Проверьте, что компонент распознаётся в целевой версии.
2. Используйте контролируемую тестовую цель и меняйте только значение урона.
3. Не делайте вывод об итоговом уроне только по одному числу, если одновременно работают другие механизмы урона.
4. Проверьте Content Log и протестируйте пример в отдельном мире.

**Статус:** карточка подготовлена по официальной странице; пример не проверен в игре.
