# Как устроен Entity Reference

Entity Reference — справочная часть Minecraft Creator documentation, в которой описаны компоненты, свойства и другие элементы схем данных сущностей. Это справочник по именам, полям, типам и ограничениям, а не замена пошаговым руководствам.

Официальная точка входа: [Entity Reference Stable](https://learn.microsoft.com/en-us/minecraft/creator/reference/content/entityreference/?view=minecraft-bedrock-stable).

## Как использовать справочник

1. Определите, какой файл редактируете: например, JSON поведения сущности в BP.
2. Найдите точный компонент по имени, включая namespace.
3. Сверьте описание и тип каждого поля.
4. Проверьте обязательность поля, значения по умолчанию и допустимые диапазоны.
5. Проверьте ограничения версии и статус Stable/Preview.
6. Перейдите по связанным компонентам, если функция зависит от других частей определения.
7. Сверьте пример с версией игры и проверяйте в тестовом мире.

## Категории, которые важно различать

- **Components** — свойства и функции, добавляемые в определение сущности.
- **Behavior goals** — задачи поведения, например движение или выбор цели.
- **Filters** — условия, используемые в компонентах и событиях.
- **Sensors** — механизмы обнаружения условий или изменений.
- **Events** — именованные изменения состояния, часто через component groups.
- **Entity properties** — пользовательские значения состояния, если они поддерживаются соответствующей системой.
- **Client entity и визуальные определения** — отдельная сторона Resource Pack, которая связывает модель, текстуры, анимации и render controllers.

Эти категории связаны, но не являются взаимозаменяемыми. Если компонент запускает событие, само событие обычно описывается отдельно; если визуальная модель не отображается, искать ошибку только в BP может быть недостаточно.

## Почему важно указывать версию

В справочнике Stable описаны функции для стабильной ветки документации. Preview может содержать новые поля и возможности, которые ещё не доступны в Stable. Не объединяйте их в одну таблицу без маркировки.
