# Компонент minecraft:health

Компонент задаёт запас здоровья сущности. Единица здоровья равна половине сердца: 20 очков — это 10 сердец.

Источник: [официальная страница minecraft:health](https://github.com/MicrosoftDocs/minecraft-creator/blob/main/creator/Reference/Content/EntityReference/Examples/EntityComponents/minecraftComponent_health.md).

## Поля

| Поле | Тип | Значение по умолчанию | Назначение |
|---|---|---:|---|
| max | целое число | 20 | Максимальный запас здоровья. Может быть выше стартового значения, чтобы сущность могла лечиться сверх начального уровня. |
| value | целое число или объект | 20 | Начальное здоровье. |
| value.range_min | целое число | не задано | Нижняя граница диапазона начального здоровья. |
| value.range_max | целое число | не задано | Верхняя граница диапазона начального здоровья. |

## Пример

~~~json
{
  "minecraft:health": {
    "value": 30,
    "max": 40
  }
}
~~~

Сущность начинает с 30 очками здоровья и может восстанавливаться до 40. Компонент сам по себе не добавляет регенерацию или иммунитет к урону.

## Начальное здоровье из диапазона

~~~json
{
  "minecraft:health": {
    "value": {
      "range_min": 20,
      "range_max": 30
    },
    "max": 40
  }
}
~~~

Используйте диапазон, если начальное значение должно выбираться из интервала. Для фиксированного значения укажите число.

## Типичные ошибки

- Путать очки здоровья и сердца.
- Задать value выше max, ожидая, что это автоматически увеличит максимум.
- Ожидать, что компонент добавит восстановление здоровья.
- Не учитывать другие компоненты, которые наносят урон или применяют эффекты.

## Проверка

Проверьте JSON, стартовое здоровье, получение урона и верхний предел лечения в целевой версии игры. Не помечайте пример как проверенный в игре, пока не воспроизвели его на конкретной версии Bedrock.
