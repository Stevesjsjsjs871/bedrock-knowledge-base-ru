# Компонент minecraft:follow_range

**Назначение:** задаёт дальность, на которой моб может преследовать выбранную цель. Это параметр дальности, а не скорости движения.

Источник: [Microsoft Learn — minecraft:follow_range (Stable)](https://learn.microsoft.com/en-us/minecraft/creator/reference/content/entityreference/examples/entitycomponents/minecraftcomponent_follow_range?view=minecraft-bedrock-stable).

## Поля

| Поле | Тип | Значение по умолчанию | Назначение |
|---|---|---|---|
| value | целое число | не задано | Дальность преследования в блоках |
| max | целое число | не задано | Максимальная дальность преследования в блоках |

Официальная документация приводит примеры для разных Vanilla-сущностей: например, 48 блоков для Blaze и 16 для Elder Guardian. Это примеры конкретных мобов, а не рекомендуемые значения для всех существ.

## Минимальный пример

~~~json
{
  "minecraft:follow_range": {
    "value": 24
  }
}
~~~

Значение 24 задаёт дальность в блоках. В реальном поведении итог зависит также от выбора цели, фильтров, AI goals, видимости и условий навигации.

## Использование value и max

~~~json
{
  "minecraft:follow_range": {
    "value": 24,
    "max": 32
  }
}
~~~

Не копируйте эту пару автоматически во все сущности. Сверьте необходимость max с текущей документацией и проверьте результат на выбранной версии. Если нужна обычная фиксированная дальность, начните с минимального примера и добавляйте ограничения только при понятной причине.

## Не путайте три параметра

- **follow_range** — как далеко моб может преследовать цель.
- **movement** — базовая скорость перемещения.
- **nearest_attackable_target** и другие AI goals — как сущность выбирает цель и начинает взаимодействовать с ней.

Увеличение follow_range само по себе не делает моба быстрее и не добавляет ему способность обнаруживать любой тип сущности.

## Диагностика

| Симптом | Что проверить |
|---|---|
| Моб не замечает игрока издалека | Дальность follow_range, фильтры выбора цели, видимость и AI goal |
| Моб видит цель, но не приближается | Навигацию, movement, ограничения среды и приоритеты поведения |
| Моб продолжает преследование слишком долго | Значения дальности и условия сброса/смены цели |
| Работает иначе, чем Vanilla-моб | Сравнить связанные компоненты и цели AI, а не только одно поле |

## План проверки

1. Создайте тестовую сущность с минимальным AI и фиксированной дальностью.
2. Измерьте дистанцию, на которой цель начинает преследоваться.
3. Повторите тест с другой величиной value, меняя только её.
4. Проверьте, может ли моб добраться до цели физически.
5. Запишите версию Minecraft, настройки мира и наблюдаемый результат.

**Статус:** справочная карточка по официальному описанию; игровой тест не заявлен.
