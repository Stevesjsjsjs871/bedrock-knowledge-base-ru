# Компонент minecraft:collision_box

Задаёт физическую коробку столкновений сущности. Она влияет на столкновения с миром и объектами, но не меняет автоматически геометрию модели или текстуру.

Источник: [официальная страница minecraft:collision_box](https://github.com/MicrosoftDocs/minecraft-creator/blob/main/creator/Reference/Content/EntityReference/Examples/EntityComponents/minecraftComponent_collision_box.md).

## Поля

| Поле | Тип | Значение по умолчанию в справочнике | Назначение |
|---|---|---:|---|
| width | число | около 0,6 блока | Ширина и глубина коробки в блоках. |
| height | число | около 1,8 блока | Высота коробки в блоках. |

Согласно источнику, отрицательные значения трактуются как 0. Практические размеры должны быть разумными и проверяться в игре.

## Пример

~~~json
{
  "minecraft:collision_box": {
    "width": 0.5,
    "height": 1.2
  }
}
~~~

## Что важно различать

- **Collision box** — физические размеры для столкновений.
- **Geometry** — форма и кости визуальной модели.
- **Render controller** — выбор геометрии, материалов, текстур и видимости частей модели.

Если модель выглядит крупной, а сущность проходит через узкие места, проверьте collision box отдельно от геометрии. Если физический размер верный, но модель визуально смещена, исследуйте геометрию и pivot.

## Типичные ошибки

- Считать width только шириной: поле задаёт ширину и глубину.
- Увеличивать геометрию, ожидая изменения физического столкновения.
- Делать коробку слишком большой относительно модели.
- Проверять только внешний вид, не испытывая движение у стен, дверей и других сущностей.
