# Компонент minecraft:movement

Компонент задаёт базовую скорость перемещения сущности. Фактическое движение зависит также от навигации, AI goals, среды и других компонентов.

Источник: [официальная страница minecraft:movement](https://github.com/MicrosoftDocs/minecraft-creator/blob/main/creator/Reference/Content/EntityReference/Examples/EntityComponents/minecraftComponent_movement.md).

## Поля

| Поле | Тип | Значение по умолчанию | Назначение |
|---|---|---|---|
| value | число или объект диапазона | не задано | Базовая скорость перемещения. |
| value.range_min | число | не задано | Минимум скорости для диапазона. |
| value.range_max | число | не задано | Максимум скорости для диапазона. |
| max | число | не задано | Максимальная скорость согласно описанию компонента. |

## Фиксированная скорость

~~~json
{
  "minecraft:movement": {
    "value": 0.25
  }
}
~~~

## Диапазон

~~~json
{
  "minecraft:movement": {
    "value": {
      "range_min": 0.20,
      "range_max": 0.30
    },
    "max": 0.30
  }
}
~~~

Не добавляйте max автоматически во все конфигурации: используйте верхнее ограничение, когда оно действительно требуется и подтверждено на целевой версии.

## Не путайте

- minecraft:movement задаёт базовую скорость.
- Компоненты вроде minecraft:movement.basic и minecraft:movement.fly задают механики движения, используемые вместе с соответствующей навигацией.
- minecraft:follow_range задаёт дальность преследования, а не скорость.
- AI goal задаёт намерение двигаться к цели, но не заменяет параметры скорости.

## Диагностика

Если моб стоит на месте, проверьте навигацию и поведение, блокирующую среду, фильтры и конфликтующие события. Не начинайте с бесконечного увеличения value.

**Статус:** черновик; поля сверены с официальной таблицей, поведение не заявлено как проверенное в игре.
