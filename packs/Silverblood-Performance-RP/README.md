# Silverblood Performance RP

Это минимальный независимый каркас Resource Pack. Он пока **не содержит переопределений текстур, частиц, тумана или освещения**, поэтому не должен рекламироваться как готовый FPS-бустер и не ожидается, что сам по себе даст прирост FPS.

## Целевые установки

- Minecraft Bedrock 1.21.51
- Minecraft Bedrock 26.50
- Основное тестовое устройство: iQOO 15R, 8 ГБ RAM

Совместимость с каждой версией не подтверждена до импорта в игру.

## Проверка

1. Упаковать содержимое этой папки в ZIP, сохранив `manifest.json` в корне архива.
2. Импортировать архив в Minecraft.
3. Проверить, что пакет отображается в списке Resource Packs и активируется.
4. Проверить Content Log на обеих целевых версиях.
5. Только после успешного базового импорта добавлять по одному проверенному переопределению.

## Правила дальнейшей разработки

- Использовать собственные идентификаторы и UUID.
- Не копировать текстуры, звуки, код или другие ассеты FPS Booster и Lithium.
- Не отключать все частицы массово.
- Для каждого изменения записывать причину, ожидаемый визуальный эффект и тест регрессии.
- Не заявлять прирост FPS без повторяемого сравнения на устройстве.
