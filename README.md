# Bedrock Knowledge Base RU

Единая русскоязычная база знаний по Minecraft: Bedrock Edition Add-Ons. Здесь собраны практические руководства, объяснения терминов и ссылки на первоисточники Bedrock Wiki и Microsoft Learn.

> **Статус проекта:** энциклопедия развивается. Полный импорт источников, смысловая проверка повторов и полный перевод ещё не завершены. Наличие статьи не означает, что каждый пример проверен в игре.

## Как пройти от примера до рабочего Add-On

1. **Выберите тему** по таблице выше или найдите её в [карте знаний](docs/ru/КАРТА_ЗНАНИЙ.md).
2. **Проверьте версию игры и статус функции.** Не переносите пример Stable в Preview или наоборот без проверки.
3. **Проверьте JSON и структуру файлов** по [руководству по схемам](docs/ru/руководства/ПРОВЕРКА_JSON_И_СХЕМЫ.md).
4. **Запустите Add-On в игре** и проверьте Content Log. Автоматические проверки репозитория не заменяют тест в Minecraft.
5. **Если результат отличается от ожидаемого**, зафиксируйте версию Bedrock, тип пакета (BP/RP), минимальный пример, сообщение Content Log и ожидаемое поведение. Это помогает отделить ошибку JSON от несовместимости или конфликта паков.

## Проверки и обновление источников

GitHub Actions запускает проверки при push и pull request: [Validate repository](.github/workflows/validate-repository.yml).

Локально:
```bash
python -m unittest discover -s tests -v
python tools/validate_repository.py
python tools/validate_performance_rp.py
```

Для синхронизации upstream-источников нужны Git и Python 3.10+:
```bash
python tools/sync_sources.py
python tools/build_catalog.py
```

Исходники сохраняются в локальной папке `sources`; полные копии материалов не публикуются автоматически.

## Принципы базы знаний

1. Каждая объединённая статья сохраняет ссылки на первоисточники.
2. JSON-ключи, идентификаторы компонентов и имена API не переводятся.
3. Stable и Preview помечаются раздельно.
4. Машинный поиск помогает находить кандидатов на дубли, но смысловое объединение требует проверки.
5. Перед копированием полного текста, кода или изображений проверяется лицензия конкретного источника.
